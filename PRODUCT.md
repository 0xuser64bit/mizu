# Mizu

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

React developers discovering, evaluating, installing and composing interfaces.
Designers exploring interaction and motion through working demonstrations.

## Product Purpose

An independent interface ecosystem of 100+ useful components and coherent
systems. The explicit brief requires exceptional craft, real interaction,
accessible controls, responsive behavior, documentation and npm consumption.

## Operating Context

Discover → preview → understand → copy/install → use. A Next.js showcase and
a separate React package share the same implementations. The archive, lab and
standpoint remain alongside searchable component documentation.

## Capabilities and Constraints

TypeScript, React, CSS tokens and Motion are already installed. Package code
must not import Next.js or website code. Native semantics, keyboard operation,
reduced motion and consumer validation are required. Public npm publication is
a release step, not evidence of completion from a local build.

## Brand Commitments

Mizu's existing identity is interface craft, with purposeful motion and readable,
inspectable code. Extend the established identity rather than replace it.

## Evidence on Hand

Working package components in packages/mizu/src; live demonstrations in
src/components/docs; the user's detailed ecosystem brief. No fabricated adoption,
benchmarks, testimonials or compatibility claims.

## Product Principles

- Quality over count; compound parts count as one system.
- Simple consumption and composition over clever infrastructure.
- Useful originality; real states over visual mockups.
- Continuous testing, documentation and coherent commits.

## Accessibility & Inclusion

Semantic HTML, labelled controls, visible focus, keyboard paths, touch targets,
contrasting text and reduced-motion alternatives are part of each component.
