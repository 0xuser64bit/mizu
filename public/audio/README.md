# Interface field notes

An original Mizu script, spoken by the macOS Daniel system voice at 158 words
per minute. Generated locally for this synthetic demonstration; no interview,
external recording, or real speaker is represented.

Each passage was generated separately, converted to mono 22,050 Hz PCM, and
joined with 550 ms of silence. `interface-field-notes.json` records the exact
PCM boundaries, transcript, and 1,024 amplitude peaks measured from that audio.
The delivery file is a 64 kb/s MP3 made from the joined PCM. MP3 decoding may
introduce a small encoder delay; the transcript is aligned by passage, not word.
